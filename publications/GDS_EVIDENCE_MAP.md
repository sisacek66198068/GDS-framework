## Reproducible benchmark already present / Existující benchmark

See [GIGAALL_FINAL_RESULT.md](../GIGAALL_FINAL_RESULT.md). The repository records best -loglike values: LCDM **1021.58**, GDS/GSC **1020.10** (difference **-1.48**) and STRING-LIKE **1567.47**. Lower is better for this metric. This comparison alone does **not** establish a statistically preferred cosmological theory: model complexity, parameter freedom, priors, full likelihood specification and independent replication remain relevant.

## Existing observation summaries / Existující observační souhrny

The existing [unified-stability notes](gds_unified_stability/README.md) report Cold Spot persistence factor ~5.93, early/late H0 ~67.37/71.94 (difference ~4.57), Great Attractor anisotropy ~0.97 and an FRB observer-layer count 973 to 514. These are **reported values from project notes**, not independently verified measurements or established explanations; consult the original publication for definitions and limitations.

## Scope boundary / Vymezení

GDS: gravitation, cosmology, collapse, structure formation, finite-core compact objects, observational comparisons. GSC-X: industrial, cardiac, robotics, fusion control, battery, internet and other application-specific Executive validation. Their PDFs remain in the shared publication archive but are not counted as primary GDS cosmological evidence.
