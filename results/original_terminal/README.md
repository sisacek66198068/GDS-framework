# GDS — Original Terminal Results

These files are byte-identical copies of selected original
research outputs from the GDS development environment.

They are separate from the publication-extracted CSV tables.

## Black-hole recycling budget

- blackhole_recycling/gds_blackhole_recycling_budget.csv
- blackhole_recycling/gds_blackhole_recycling_budget_summary.csv

These are model-based exploratory mass-budget calculations.

They do not measure astrophysical core masses and do not
establish physical black-hole recycling or cosmogenesis.

## GDS v4 passive metastability corridor

- gds_v4_passive_corridor/GDS_V4_METASTABLE_CORRIDORS.csv

This is a frozen passive diagnostic result of GDS v4.

It is not an independently validated active gravitational
mechanism and must not be confused with the published
GDS v3 cosmological benchmark.
